# Specification and Workflow Documents

These documents define the platform-neutral visual/interaction contract and the current Codex Skill workflow.

- [Visual specification](visual-specification.md) — optical material anatomy, shape families, quality tiers, and visual review criteria.
- [Interaction and motion](interaction-and-motion.md) — state model, connected-shape transitions, motion behavior, accessibility, and motion review.
- [Reference matrix](reference-matrix.md) — maps still images and the inspected motion reference to specific review criteria.
- [Skill installation](skill-installation.md) — install, update, and validate the portable Codex Skill.
- [Platform adaptation](platform-adaptation/README.md) — capability matrix, platform-family routes, and validation guidance.

Read the visual specifications before implementing platform-specific rendering. They describe the desired result, not a mandated rendering stack. The Skill is the operational workflow for discovering a target project and applying those specifications.
