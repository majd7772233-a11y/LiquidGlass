# Changelog

All notable project packaging and behavior changes are recorded here. Versions follow Semantic Versioning for the standalone Skill package. The private Studio plugin maintains its package version in `studio/package-source/plugin.json`.

## 0.1.0 — prepared, not yet tagged

- Added a self-contained, versioned Liquid Glass Skill archive builder.
- Added PowerShell install and uninstall scripts with backup and scope safeguards.
- Added a Windows clean-install/update/uninstall workflow test.
- Added release, provenance, license-boundary, and contribution documentation.
- Documented the existing private Liquid Glass Studio installation and its account-bound GitHub connector setup.
- Kept physical-device GPU, battery, thermal, TalkBack, and real-browser GPU validation as maintainer-owned release gates; no stable release tag is created until that evidence is recorded.
